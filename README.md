# Nik Stagno Navarra — Portfolio

Personal portfolio site for Nik Stagno Navarra, Digital Product Manager specialising in mobile, payments, and high-scale consumer platforms.

## Tech Stack

- **Framework:** Next.js (static export)
- **Styling:** Tailwind CSS
- **Font:** Space Grotesk

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view locally.

## Production Build

```bash
npm run build
```

Static files output to `out/` directory. Deployed with basePath `/portofolio`.
